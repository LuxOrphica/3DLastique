# VSE — Visual Standardization Engine

Система автоматической стандартизации технических чертежей одежды.

---

## Что это

Конструкторы одежды работают с техническими чертежами в Adobe Illustrator (AI-файлы).
Каждый файл — один конструктивный узел: молния спереди, кромка воротника, усиление, шлёвка и т.д.
Чертежи нарисованы вручную — у каждого свои цвета, толщины, стили линий.

**VSE** читает AI-файлы, классифицирует каждый путь (контур, строчка, шнур, выноска...) и выдаёт стандартизированный SVG — с единой цветовой схемой и толщинами по роли.

Цель: библиотека из ~4116 узлов, все в едином визуальном стандарте, пригодная для Tech Pack.

## Pipeline: как AI превращается в SVG

```
AI-файл (Adobe Illustrator)
    ↓  pymupdf: извлечь пути, цвета, толщины
    ↓
[Уровень 1] Первичная классификация (roles.py)
    — по цвету: красный → строчка, синий → выноска, зелёный → подкладка
    — по геометрии: дашед, замкнутый, размер, ориентация
    — по контексту: рядом с текстом → break_line / label
    ↓
[Уровень 2] Контекстные уточнения (roles.py)
    — текст содержит "cord" → fill_cord
    — текст содержит "elastic" → fill_elastic
    ↓
[Уровень 3] Реестр стилей (engine.py)
    — ищет точное совпадение по (stroke|fill|width|dashed|orient|sz) в style_registry.json
    — если есть — перекрывает уровень 1-2
    ↓
[Уровень 4] Post-processing (engine.py)
    — merge_stitch_thru_rows: объединить фрагменты строчки в цельную линию
    — sanitize_color_role_conflicts: красный не может быть подкладкой
    — add_buckle_fills: добавить белую заливку под пряжки
    — render_zipper_clusters: нарисовать SVG-символ молнии
    ↓
{id}_std.svg с ролями, цветами и толщинами по стандарту
```

## React Workbench (VseReview.jsx)

Инструмент для просмотра и правки классификации нодов.

**Что умеет:**
- Навигация по всем 4116 нодам с фильтром по категории и поиском
- Сравнение оригинала и стандарта бок-о-бок (масштаб, перетаскивание)
- Подсветка элемента при наведении на строку таблицы (оба SVG)
- **Live preview**: смена роли в dropdown → стиль элемента меняется сразу в SVG
- Пересборка стандарта для одного ноды (кнопка "Сгенерировать стандарт")
- Пометка нода как "Утверждён" или "Сложный" (сохраняется в localStorage + API)

**Таблица ролей:**
- Группирует пути из `{id}_std.svg` по (role | stroke | fill | width | dashed)
- Показывает превью линии, цвет, толщину, количество, dropdown для смены роли
- При смене роли применяет CSS override с `!important` к SVG элементам

## Реестр стилей (style_registry.json)

Накопленная база: какой визуальный стиль (цвет + толщина + геометрия) → какая роль.

Редактируется через Workbench: выбрал роль в dropdown → нажал "Сгенерировать стандарт" → запись сохраняется в реестр → при следующем экспорте все похожие элементы во всех нодах получат эту роль.

**Ключ записи:** `stroke | fill | width | dashed | is_line | is_filled | is_tiny | is_closed | near_text | orient | sz`

## Статус (июнь 2026)

**Реализовано:**
- Pipeline классификации (4 уровня) для ~40 категорий конструктивных узлов
- Реестр стилей (~6000 записей, накоплен на ~2800 нодах)
- Экспорт orig + std SVG для всех включённых нодов
- Workbench: навигация, сравнение, live preview, одиночная пересборка
- Система утверждения нодов (approved / complex)
- Post-processing: мерж строчек, молнии, пряжки, кольца
- Per-node overrides для специфических файлов (RE00004 и др.)

**В работе / известные проблемы:**
- Категории аксессуаров 200+ требуют ручной правки ролей
- Наложение частей детали: global layer order не подходит — нужен per-node порядок
- VSE visual issues: перехлёст контурных линий, разрывы ритма строчек
- Интарсия-зоны: конвертация фрагментов через intersect/diffMulti (запланировано)
