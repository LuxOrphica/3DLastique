# Canonical Role Styles

Черновая каноническая таблица ролей для Visual Standardization Engine.

Цель этого слоя:

- не менять входную классификацию AI/PDF;
- сделать standard render однозначным;
- постепенно развести роли, которые исторически были нарисованы одинаковыми стилями.

Важно:

- `key_str` в исходной библиотеке описывает внешний вид, а не смысл;
- поэтому канонические стили применяются на этапе standard render;
- точечные и node-level overrides по-прежнему нужны для ручной доводки.

## Принципы

1. Одна устойчивая роль должна иметь один канонический стиль в standard output.
2. Если две разные роли раньше выглядели одинаково, на первом этапе их можно разводить минимально:
   - по толщине (`0.1`–`0.4`);
   - реже по цвету.
3. На входной классификации нельзя полагаться только на стиль:
   - в исходной библиотеке один и тот же стиль может значить разные вещи.
4. `fill_white_detail` и `fill_material_mask` никогда не должны смешиваться:
   - первая роль видима;
   - вторая служебная.
