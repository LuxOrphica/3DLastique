# VSE Encoding Rules

- Все текстовые файлы проекта храним только в UTF-8.
- JSX, JSON, MD и Python нельзя сохранять из редакторов, которые тихо переключают кодировку на CP1251 или ANSI.
- Если в UI появились серии вопросительных знаков или похожие кракозябры, не чиним это “на глаз” вслепую. Сначала запускаем проверку кодировки.
- Перед сдачей работы по VSE обязательно запускать:

```bash
npm run check:encoding
```

- Коммит с битой кириллицей или mojibake не должен проходить pre-commit hook.
- Базовый минимум перед отчетом по VSE:

```bash
npm run check:encoding
npx vite build --outDir dist-check
```
